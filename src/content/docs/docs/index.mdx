# RTMX

<Badge text="v0.0.5" variant="tip" />

**RTMX Sync is the product** — a live room where humans and agents share
requirements, claims, and status. The open-source `rtmx` CLI is how you enter
that room: install the client, sign in, and join Sync.

These docs cover the client: local RTM databases, commands, markers, and MCP.
For the product thesis and trial, see [RTMX Sync](/sync).

## Why RTMX?

<CardGrid>
  <Card title="For AI-assisted development" icon="rocket">
    Token-efficient CSV format that fits in context windows. Clear requirement IDs for precise references (`REQ-AUTH-001`). Dependency graphs that show what to build next.
  </Card>
  <Card title="For teams" icon="seti:config">
    One command to see project progress: `make rtm`. Prioritized backlog with blocking dependencies. Tests linked directly to requirements.
  </Card>
  <Card title="For compliance" icon="approve-check">
    Every requirement linked to its test. Audit-ready CSV database (version-controlled, diff-friendly). Validation that catches gaps before reviewers do.
  </Card>
  <Card title="For agents" icon="setting">
    MCP server for AI agent integration. Agents can query status, update requirements, and discover dependencies.
  </Card>
</CardGrid>

## Quick Start

```bash
pip install rtmx
rtmx setup
rtmx status -v
```

This creates everything you need:
- `rtmx.yaml` — Configuration file
- `docs/rtm_database.csv` — Requirements database
- `docs/requirements/` — Requirement specification files
- Makefile targets (`make rtm`, `make backlog`)
- AI agent configs (AGENTS.md, .cursorrules)
